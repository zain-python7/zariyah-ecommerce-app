# Zariyah E-Commerce App 🛍️

A Flutter-based e-commerce mobile application designed to provide users with a smooth and organized online shopping experience.

Zariyah allows users to explore product categories, view products, manage a shopping cart, maintain a wishlist, and interact with other shopping features through a clean and user-friendly interface.

## ✨ Features

- **Product Categories:** Browse products organized into categories.
- **Product Browsing:** Explore available products and view product details.
- **Search:** Find products more conveniently, if implemented in the current version.
- **Shopping Cart:** Add and manage products before checkout.
- **Wishlist:** Keep track of favorite products.
- **Checkout:** Access the order checkout flow.
- **Order History:** Review previous orders, if available in the current version.
- **Local Data Storage:** Store supported application data locally using SQLite.
- **User-Specific Shopping Data:** Designed to keep shopping information separate between accounts.
- **User-Friendly Interface:** Navigate the application through a Flutter-based interface.

> Note: Features listed above should match the functionality implemented in the current version of the application.

## 🚀 Getting Started

### Prerequisites

Install the following tools:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or another supported development environment
- Git

### Installation
 

 Install the project dependencies:

   ```bash
   flutter pub get
   ```

 Check for available devices:

   ```bash
   flutter devices
   ```

 Run the application:

   ```bash
   flutter run
   ```
